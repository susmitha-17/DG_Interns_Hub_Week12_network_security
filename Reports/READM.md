# Week 12 – SOC Final Capstone: Threat Detection & Incident Response

**Internship:** DG Interns Hub  
**Module:** SOC Final Capstone  

## Overview
This capstone focuses on performing a SOC investigation in an authorized lab environment, covering security monitoring, threat detection, incident investigation, evidence collection, and incident response using Wazuh SIEM and Snort IDS.

## Tasks Completed / Documented

1. **SOC Lab Setup:** Configuring and verifying Ubuntu, Wazuh Manager, Agent, Dashboard, Snort IDS, and test endpoint.
2. **Incident Simulation:** Performing a controlled security incident simulation in the authorized lab.
3. **Threat Detection:** Identifying suspicious activity through security alerts, logs, IP addresses, ports, and detection rules.
4. **Incident Investigation:** Analyzing events, affected systems, evidence, potential impact, and incident classification.
5. **Snort + Wazuh Correlation:** Correlating network-based and host-based security events to build an incident timeline.
6. **IOC & Evidence Collection:** Identifying and documenting IP addresses, ports, usernames, file paths, timestamps, and rule identifiers.
7. **Incident Response:** Applying the Preparation, Identification, Containment, Eradication, Recovery, and Lessons Learned stages.
8. **SOC Incident Ticket:** Preparing a structured incident ticket with investigation findings, severity, evidence, and recommendations.
9. **SOC Metrics:** Documenting event statistics, alert classifications, severity distribution, and detection sources.
10. **SOC Analyst Reflection:** Summarizing technical learning, challenges, practical experience, and future improvements.

## Deliverables
- Detailed SOC Capstone Report (DOCX/PDF)
- SOC Capstone Presentation (PPT)
- Lab screenshots and technical evidence
- Incident timeline and IOC analysis
- SOC incident ticket and metrics
